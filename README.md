# Vagas Estágio

Landing page para divulgação de vagas de estágio.

## Sobre o projeto

O projeto consiste em uma landing page onde é possível cadastrar uma vaga de estágio por meio de um formulário. Após o preenchimento, a vaga cadastrada é adicionada automaticamente à tabela de divulgação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Cadastro de vagas de estágio;
- Formulário com informações da vaga;
- Exibição das vagas cadastradas em uma tabela;
- Adição dinâmica de novas vagas;
- Validação dos campos obrigatórios;
- Layout responsivo.

## Objetivo

Desenvolver uma página para divulgação de oportunidades de estágio, utilizando conceitos de desenvolvimento web e interação com formulários.

## Observação

Os dados cadastrados são exibidos apenas durante a utilização da página e não são armazenados em um banco de dados.
